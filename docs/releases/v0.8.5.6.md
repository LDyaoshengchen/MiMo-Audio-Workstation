# MiMo Audio Workstation v0.8.5.6

Windows x64 更新，包含自 v0.8.5 以来的修复与体验优化。

## 本次更新

- 收藏音频按角色名称自动保存到当前数据目录的 `role-voice-library` 文件夹；已有收藏打开角色库时自动补齐，保留原音频格式和内容。
- 同名不同音频自动编号，不覆盖已有文件；取消收藏或删除角色时保留本地音频副本。写入失败不会误报保存成功。
- 整合与产物节点支持收藏，已收藏显示同色实心星；保存、取消收藏、删除及重新打开后的状态同步。
- 收藏改为小型命名弹窗，保存操作不再被底部遮挡；角色库使用紧凑三列，小窗口自适应两列或单列。
- 生成过程中可自由切换画板，原画板在后台继续生成并保存，切回后恢复进度和结果；其他画板可以继续编辑。
- 修复参考音频替换与清空的优先级，避免旧 Voice ID 或隐藏参考音频影响当前生成。
- 修复中文存储目录选择和迁移提示，显示迁移预计时间；角色库随数据目录迁移。
- 右键拖动画布时自动收起新建节点菜单；改进小窗口顶部设置和版本更新识别。

## 下载与升级

- `MiMo-Audio-Workstation-Setup-v0.8.5.6-win64.exe`：安装版。
- `MiMo-Audio-Workstation-v0.8.5.6-win64-portable.zip`：便携版，解压后运行 `MiMo-Audio-Workstation.exe`。
- 请等待生成和保存完成，完全退出旧程序后再更新。跨画板后台生成要求软件保持开启，退出软件后不会继续生成。
- 使用原数据目录即可保留画板和角色库。旧版若仍提示“已是最新”，请从此发布页手动下载更新一次。
- 程序未配置代码签名，Windows 可能显示未知发布者提示。
