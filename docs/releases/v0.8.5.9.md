# MiMo Audio Workstation v0.8.5.9

Windows x64 更新，包含规整排版句段智能排序、批量产物命名修正与角色音色库分组等体验优化。

## 本次更新

- **规整排版句段智能排序**：在批量产物节点未自定义命名时，自动关联父节点行顺序与句段编号，整理排版时严格按照「句段 1、2、3、4、5...」顺序规整排列，解决节点拖动或异步生成后 Y 轴乱序导致的排版错位问题。
- **批量产物音频命名与暂存一致性修复**：当批量克隆节点与批量产物节点未显式命名时，优先取用批量行的「标识/名字」，卡片音频显示与暂存产物命名保持完全一致，不再错误回退到“句段 1”或“产物_01”。
- **角色音色库分组管理**：支持角色音色库新建分组、按组筛选、快速归组，以及分组重命名与安全删除（保留角色与音频文件）。
- **生成过程位置实时跟随与空位补齐**：生成任务执行中整理画布后，新产物能够智能跟随最新网格排版，删除产物后自动识别空位并补齐。
- **画板架构解耦与体积优化**：抽离整理排版算法与暂存命名逻辑，单文件代码规范与边界测试全面通过。

## 下载与升级

- `MiMo-Audio-Workstation-Setup-v0.8.5.9-win64.exe`：安装版。
- `MiMo-Audio-Workstation-v0.8.5.9-win64-portable.zip`：便携版，解压后运行 `MiMo-Audio-Workstation.exe`。
- 请等待生成和保存完成，完全退出旧程序后再更新。
- 使用原数据目录即可完整保留画板、音色库及设置数据。旧版若仍提示“已是最新”，请从此发布页手动下载更新安装。
- 程序未配置商业数字代码签名，Windows SmartScreen 可能显示未知发布者提示，点击“更多信息”->“仍要运行”即可。
